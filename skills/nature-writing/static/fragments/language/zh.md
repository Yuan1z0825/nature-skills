# Language: 中文写作（Chinese target, writing）

Use this when the manuscript or section is to be drafted or restructured **in
Chinese**（中文期刊、学位论文、中文会议稿、项目结题报告等）。论证架构
（gap → design → discovery → implication）不变，变的是句子与段落惯例。
如果目标是 Nature 系英文期刊，不要走本片段，应走 `zh-to-en`。

## Workflow

1. 先列出作者证据支持的核心命题（claim / evidence / condition /
   comparison / implication / limitation），再按目标章节的要求排序成段。
2. 先搭逻辑后写句子：段内每句话与前一句有明确关系（因果、对比、限定、
   例证），不靠"此外/另外"硬接。
3. 建立 Terminology Ledger：术语首次出现给出全称（必要时附英文对照），
   之后全文只用规范简称。
4. 证据缺失或边界不清处，标注出来请作者补充，不用漂亮话掩盖。

## Sentence rules（句子层面）

- 一个句子一个核心命题；中文允许比英文更长的句子，但超过约 80 字必须
  检查是否含多个命题，含则拆句，不用逗号硬连。
- 至多一层"通过/利用……"状语套叠，避免"通过……从而……"式长链。
- 用实义动词起草，直接写"分析表明""实验显示"，避免"进行了分析"
  "实现了提升"这类空转表达。
- 的、地、得使用正确；名词化链条（"……的……的……"）超过两层时拆句。
- 主语省略以不产生歧义为限；连续短句主语相同时合理承前省略，不逐句重复。

## Paragraph rules（段落层面）

- 一段一个中心意思，首句即主题或主张。
- 支撑材料可以是数据、对比、解释、后果、文献或限定，但要与中心句有
  明确关系。
- 新意思另起一段，不把两个主张堆进同一段。
- 段落末句最常写得最长最弱，逐段检查。

## Diction（用词）

- 动词与证据强度匹配："表明 / 提示 / 可能"，不过度断言也不含糊。
- 避免宣传性动词和空喊式定性："首次""创新性""国际领先""填补空白"
  必须有明确边界（哪个范围、与什么比），否则改写为有边界的贡献陈述。
- "显著提高 / 明显改善"必须给出基线或比较对象；没有就软化动词或补数据。

## Output convention

- 输出中文正文，附简短的写作说明（3-5 条），解释主要的结构选择
  （如缺口前移、拆分长句、限定词归位），便于作者核对意图。
- 统计数字、单位、限定条件与作者提供的证据完全一致，不四舍五入改写。
