## Part II 导言

Part II — The Eight-Step Workflow（八步工作流）。

本部分收录八步工作流中的前三步：Step 1 定义研究问题空间、Step 2 绘制研究版图、Step 3 定位未决研究问题。三步依次承担"划界探索范围 → 看清领域结构 → 判断知识困难是否真实存在"的职能。

## 步骤 1 — Define the Research Search Space ｜ 定义研究问题空间

> 划出一片足够宽又足够窄的探索范围，让替代解释和问题浮现。

### 目标（What are you trying to achieve?）

产出一页研究问题空间说明。读完它，一个不熟悉你想法的人应该能看出：

- 你真正被什么现象或过程吸引；
- 这片领域可能包含哪些不同含义；
- 可能涉及谁、什么材料、什么情境和尺度；
- 哪些边界尚未决定；
- 哪些个人和现实约束会影响后续选择。

空间要足够宽，能让替代解释和不同问题浮现；也要足够窄，可以进行一次认真而有限的文献探索。

### 为什么重要（Why does this matter?）

跳过这一步，最容易出现三种错误。

第一，把兴趣直接写成问句。"我对照护感兴趣"很重要，但"照护如何影响社会？"只是加了问号，仍然没有研究边界。

第二，把两个宽泛词连接起来。"社交媒体与身份认同"可以包含平台治理、自我呈现、群体归属、职业身份、政治身份和无数人群。Codex 会轻易为这种表达生成十个流畅题目，却无法判断哪一个进入了真实的学术争论。

第三，过早锁定资料或方法。你可能因为手上有某份问卷，就把其中的字段当成目标概念；也可能先决定做访谈或机器学习，再为工具寻找问题。

研究问题空间让你暂时保留选择，同时阻止范围无限扩张。

### 需要什么输入（What do you need to give Codex?）

先写下你当前知道的内容。不确定的地方直接写"不确定"。

我的起点属于：Mode A / Mode B / Mode C

我感兴趣的现象、过程或主题：

我已经想到的参与者、人群、组织或材料：

可能相关的地点、制度或历史情境：

我关心的时间范围或变化过程：

我已经接触过的概念、理论或文献：

我不想研究的内容：

实践上的硬约束：

例如语言、地点、时间、预算、数据权限、伦理、方法基础。

目前最不确定的地方：

个人兴趣不需要包装成客观重要性。你可以说"这来自我的实习经历"或"我读到这个争论后一直不服气"。Codex 之后仍需检验它是否对应值得研究的知识问题。

### 应该做什么（What should Codex do?）

Codex 应完成五项工作。

5. 拆解概念。列出核心表达可能包含的不同现象或过程，并指出哪些不能直接混为一谈。
6. 扩展相邻词汇。提供其他学科或文献可能使用的术语，避免后续只搜到一种表达。
7. 提出边界选项。展示不同参与者、材料、情境、时间和尺度会如何改变探索范围。
8. 暴露预设。指出你的描述是否已经假定了方向、因果、价值判断或某种方法。
9. 形成搜索范围。给出一个暂定的纳入/排除框架和需要核实的决定。

Codex 不应生成候选博士问题，不应宣称某方向新颖，也不应因为某数据或材料容易获得就替你选定范围。如果它开始列研究问题，请停止它，并要求返回概念和边界构建。

这一阶段通常不需要大规模文献搜索。若 Codex 为澄清术语而查询资料，应说明来源层级和不确定性，不能把初步搜索写成领域结论。

### 通过标准（How do you judge whether the result is good?）

用下面七项检查：

- [ ] 读者能否在一分钟内说出你要探索的学术领地？
- [ ] 核心概念是否被拆开，而不是换成更多同义词？
- [ ] 参与者或材料、情境、时间和尺度是否都有候选边界？
- [ ] 输出是否保留了至少两种可能方向，而非偷偷选定一个题目？
- [ ] 个人兴趣和学术重要性是否被分开记录？
- [ ] 实际约束是否真的影响边界，而不是放在最后当备注？
- [ ] 输出是否没有候选研究问题、新颖性结论和方法炫技？

如果其中三项以上答不上来，先不要进入第二步。

Red flags

- "这是一个非常重要且研究不足的领域"，却没有证据。
- 把你的原话扩写成一页，没有真正拆解含义。
- 一次列出二三十个相关概念，彼此关系不清。
- 直接给出十个博士问题或论文标题。
- 因为某国、某人群"研究较少"就推荐它。
- 默认问卷、访谈、机器学习或因果设计。
- 用"影响""导致""塑造"写出尚未验证的方向。
- 忽略你无法旅行、没有语言能力、无法接触参与者等硬约束。
- 把"不确定"自动补成具体事实。

如果出现这些输出，直接回复："停止生成问题。请回到研究问题空间，只做概念分解、边界方案和待决定事项。"

### 状态与门禁（Status / Gate）

PASS

你有一份边界清楚但仍允许探索的搜索空间；核心概念已经拆解；硬约束和待定项可见。

下一步：进入第二步，用这份空间绘制研究版图。把相邻概念和排除项一并交给 Codex。

REVISE

你的兴趣仍值得探索，但空间太大、太窄、由数据或方法主导，或者核心词仍然混乱。

下一步：选择一个具体问题修订，例如只重做概念边界、材料边界或时间尺度。修改后重新运行本章提示词，不要进入问题生成。

STOP

当前方向与你的长期兴趣不符，触及无法接受的伦理问题，或在不可改变的语言、地点、时间和访问条件下无法开展。

下一步：保存停止原因。回到入口诊断，从更宽的兴趣重新进入，或暂时搁置，等现实条件变化。

### 交接（Handoff）

- **Carry forward（带往下一步）**：暂定研究问题空间——已拆解的核心概念、相邻概念与检索词、边界方案、明确排除项、硬约束与待决定事项。PASS 段要求"用这份空间绘制研究版图，把相邻概念和排除项一并交给 Codex"。
- **Leave behind（留在本步）**：候选博士研究问题（Codex 不应生成）；新颖性结论；方法炫技；把"不确定"自动补成的具体事实。
- **Human decision（必须人来定）**：哪个现象值得你连续读三四年；哪些个人经历是兴趣来源、哪些不适合变成研究对象；你愿意接近哪些人、机构或敏感材料；哪种学术对话更像你想加入的领域；哪些限制不可妥协、哪些能力可通过训练获得；缩小范围之后是否仍让你好奇。请把选择写入工作表，不要只保留 Codex 的推荐。
- **Blocking unknown（阻塞性未知）**：解释重点尚未选择；档案开放年份、目录完整性和复制规则尚未核实；当前语言/地点/时间/访问条件是否真能满足。

## 步骤 2 — Map the Research Landscape ｜ 绘制研究版图

> 按问题结构（而非论文清单）画出领域地图，主动搜出反证。

### 目标（What are you trying to achieve?）

研究版图（research landscape）回答的不是"我读过哪些论文"，而是"这个领域把问题分成了哪些部分，又在哪些地方发生争论"。

一篇常规文献综述往往服务于已经确定的问题。你现在还在选题，任务不同。你需要先看清：学者通常问什么、借助哪些理论解释、使用什么证据、哪些发现相对稳定、哪些判断互相冲突，以及哪些边界使结论不能直接外推。

建立一张按研究结构组织的领域地图，至少包含：

- 主要问题家族；
- 常用理论和概念框架；
- 被提出过的研究机制（mechanism）；
- 核心争论与竞争性解释；
- 常见证据与资料类型；
- 主流方法及其适用范围；
- 相对稳固的发现；
- 矛盾结果、零结果和反向关系；
- 人群、时间、情境和尺度边界。

这张地图不是为了证明你的起点正确，而是为了判断你的起点位于哪场对话中，是否需要换词、拆分或转向。

### 为什么重要（Why does this matter?）

如果你按"论文 A 说……论文 B 说……论文 C 说……"来记笔记，读到最后可能知道很多结论，却仍不知道它们为什么不同。

例如，两项研究看似都讨论"数字平台与政治参与"，一项测量的是看到政治内容，另一项研究的是加入线下组织；一项关注青年，另一项关注全部成年用户；一项比较个人差异，另一项追踪平台规则变化。把两篇摘要并排放置，不会自动形成争论。

另一种风险是确认偏误。学生先认定"某个现象会削弱另一现象"，Codex 很容易找到一批方向相同的材料，再把数量写成共识。研究版图必须主动搜索：

- 与主张相反的结果；
- 没有发现关系的零结果；
- 关系只在特定条件下成立的结果；
- 原本被当作结果的现象反过来影响起点条件的证据；
- 使用不同术语讨论同一过程的相邻文献。

只有这样，你才知道所谓"矛盾"是发现真的冲突，还是研究对象、概念、时间与尺度根本不同。

任何不确定项：

如果你有一两篇种子文献，可以附上标题、DOI、链接或 PDF。没有也可以。不要只给 Codex 一个结论，让它"找证据证明"。

### 应该做什么（What should Codex do?）

Codex 要从多个词汇入口搜索，并把找到的材料放入同一张结构图。

先扩展检索语言

不同学科可能用不同词描述相似现象。Codex 应区分核心概念、近义词和相邻概念，再组合搜索。它还应查看关键文献引用了谁、后来又被谁引用，避免只依赖一个关键词。

再按问题组织材料

输出应以"问题家族""理论解释""争论""边界"为标题。单篇论文只在支持某一结构判断时出现。不要让文献列表成为正文的骨架。

主动寻找削弱起点的材料

Codex 必须搜索矛盾、零结果、反向关系和替代解释。如果相关证据没有找到，应写"本轮未找到"，并说明搜索边界，不能写成"并不存在"。

标明证据层级

重要判断至少标成以下一种：

- METADATA ONLY：只核对了题录；
- ABSTRACT LEVEL：判断主要来自摘要；
- FULL-TEXT LEVEL：核对过论文全文；
- PRIMARY/OFFICIAL：来自一手材料或官方文档。

普通学生不需要维护复杂的证据数据库，但需要知道一条结论到底读到了哪里。

保留边界和失败

Codex 应记录检索日期、主要检索式、语言和时间限制、无法访问的关键来源，以及它没有覆盖的相邻领域。搜索失败不是新颖性证明。

The idea changed here

冻结的住房案例没有只搜索"住房不稳定导致社会联系下降"。它同时找到负向、零结果、补偿性变化和反向关系。有的移动改变地方联系，却不减少可获得支持；社会关系本身也可能影响人是否搬家。研究版图因此从单向影响转向条件性和双向过程。这里的教训不是某一条住房结论，而是：反证会改变问题的结构。

- 所有来源都支持你的初始判断。

## 步骤 3 — Find an Unresolved Research Problem ｜ 定位未决研究问题

> 把版图中的冲突、竞争解释与测量限制，提炼成有科学不确定性的未决问题。

### 目标（What are you trying to achieve?）

"这个主题很少有人研究"通常还不是博士研究问题。

研究少只能说明覆盖不足。它没有告诉你：现有认识哪里出了困难，为什么这个困难值得解决，或者新研究能让我们理解得有什么不同。一个强的未决研究问题（unresolved research problem），需要把已知、冲突、后果和可辨别的证据接起来。

这一章是前四步的中心。前两步帮你划出领域、看清版图；这一章决定其中是否真的存在值得博士工作承担的知识困难。

REFERENCE BOX — RESEARCH PROBLEM

研究难题不是"某主题研究得少"。它是现有知识中的具体困难，例如结果互相冲突、解释无法区分、过程看不见或测量错位。一个研究难题还要说明：解决它以后，我们会理解得有什么不同。

从研究版图中提取 3 至 7 个未决问题。每个问题都要说明：

- 已有研究大致知道什么；
- 哪个解释、机制、测量、时间过程或边界仍然不清；
- 这个不确定性为什么会影响我们对现象的理解；
- 什么证据有可能区分不同解释；
- 它是科学问题，还是仅仅研究覆盖较少。

此时仍不需要写最终研究问题句。一个研究问题可以支持多种问法和设计。先把"为什么值得问"说清楚，再进入第五步生成候选问题。

先对任何候选做下面四问。四问中只要有一问只能回答"因为以前没人做"，就先不要放行。

1. 我们已经知道什么？
2. 究竟什么仍然无法解释、存在争议或没有被妥善观察？
3. 为什么解决它会改变现有理解？
4. 什么证据能够区分这些可能性？

后文会展开这四问。现在先把它们当作贯穿整章的判断工具。

### 为什么重要（Why does this matter?）

博士申请中最常见的薄弱论证，是把四句话连在一起：

这个现象很重要。已有很多研究。很少有研究关注某个群体或国家。因此，本研究将填补空白。

问题在于，最后一句没有从前面的知识中推导出来。即使某个群体没有被单独研究，也可能没有理由预期现有解释会改变；即使某国研究很少，也不代表换地点能产生理论贡献。

另一个常见问题是先决定"我要研究影响"，再把所有复杂性压进一个箭头。真实的领域可能存在反向关系、共同原因、过程差异和测量冲突。把它们忽略掉，问题会显得简洁，却无法产生可信解释。

第三步迫使你回答：究竟是什么还没有被理解，而不仅是什么还没有被做过。

### 应该做什么（What should Codex do?）

Codex 应从版图中寻找不同类型的知识困难，并对每个候选问题做强度检查。

1. 区分科学问题与覆盖不足

Codex 必须问：缺少这项研究，让我们无法判断什么？如果答案只是"不知道这个关系是否也出现在群体 Z"，它需要继续追问：为什么 Z 会改变机制、测量、边界或理论预期？

2. 把争论写成可区分的解释

"文献结论不一致"仍然太宽。Codex 应尝试说明：研究可能因为概念不同、对象不同、时间窗口不同、尺度不同、方法偏差，还是因为确实存在竞争机制而得出不同结论。

REFERENCE BOX — MECHANISM

机制是一个现象如何被产生、维持或改变的过程。它不等于中介变量、访谈主题或一串可能原因。你应该能说出相关行动者或条件、过程顺序，以及不同机制会在数据、叙述、行为、文件或历史记录中留下什么不同痕迹。

3. 不把方法缺口当贡献

"尚未使用机器学习""缺少纵向研究""没有访谈"都只是设计描述。Codex 要说明，现有证据因为缺少哪种观察而无法解决什么问题。方法只有在改变可观察内容或判断能力时才重要。

4. 给问题标注类型

每个候选至少归入一个主要类型：矛盾发现、竞争解释、机制不清、测量失败、时间过程、异质性、尺度错位、新证据使旧问题可回答，或有科学理由的文献整合。

5. 寻找会终止问题的证据

如果最接近的研究已经直接解决了同一知识困难，Codex 应把问题标为可能已解决，而不是换一个国家继续包装。必要时做一轮有边界的补充检索，并标明证据层级。

九种较强的问题结构（以下示例都只展示写法。真实使用时必须由文献和证据支持。）

1. 矛盾发现

弱：有些研究认为远程办公提高归属感，另一些认为会降低，因此需要更多研究。

为什么弱："更多研究"没有解释分歧来自哪里，也没有说明怎样的观察能推进判断。

更强：现有结果可能把自愿选择的远程安排与组织强制安排混在一起。若控制感带来好处，而互动机会减少带来损失，两种机制可能同时存在，并在不同安排下占主导。需要能区分选择权、互动结构和归属变化的证据。

2. 竞争解释

弱：需要研究志愿者为什么停止参与。

为什么弱：它只描述结果，没有说明哪些解释在竞争。

更强：退出可能来自时间资源枯竭，也可能来自组织内缺乏承认。两种解释对"退出前工作负担变化"和"互动中被认可的经验"有不同预期，区分它们会改变组织留任问题的解释。

3. 机制不清

弱：学校纪律政策可能影响学生出勤，需要研究其中机制。

为什么弱："机制"只是一个占位词。

更强：政策可能通过实际停学减少上课时间，也可能通过预期惩罚、与教师关系恶化或家庭应对改变出勤。不同路径需要不同时间顺序和过程材料；只比较有无政策不能说明哪条路径成立。

4. 测量失败

弱：现有研究对新闻使用的测量不够好。

为什么弱：没有指出测量错误会改变什么结论。

更强：点击、停留和自报"看过"分别捕捉接触、注意和记忆。若研究用点击代表理解，就可能把短暂曝光解释成信息获得。区分这些构念会重新界定平台使用与政治学习之间的关系。

5. 时间过程未被捕捉

弱：照护责任与职业认同之间缺少纵向研究。

为什么弱："纵向"只是方法标签。

更强：一次性比较无法区分照护开始前的职业差异、照护初期的短暂冲击和长期适应。若身份变化发生在预期、进入或持续照护的不同阶段，理论解释和干预时点都会不同。

6. 异质性未解释

弱：自动化公共服务对不同群体的影响不同。

为什么弱：列出群体差异不等于解释差异。

更强：人们对自动化决定的信任可能取决于以往行政接触、申诉能力和错误成本。群体差异若由这些制度经验产生，就不应被写成固定的人口属性。

7. 尺度错位

弱：社区绿化可能提升居民归属感，但结果不一致。

为什么弱：绿化和归属可能在不同空间尺度被测量。

更强：行政区绿化覆盖、居民实际活动空间和其认同的"社区"边界并不相同。若证据尺度不一致，零结果无法判断绿化无关，还是测量没有覆盖居民使用的地点。

8. 新证据使旧问题变得可回答

弱：新数字化的劳动仲裁档案此前无人用过。

为什么弱：新材料本身不是贡献。

更强：若旧研究只能看到最终裁决，新开放的立案、调解和裁决序列可能让研究者观察案件如何被重新分类。它的价值在于检验制度筛选过程，而不是档案刚刚数字化。

9. 有科学理由的文献整合

弱：把迁移研究和家庭研究结合起来，形成跨学科创新。

为什么弱：两个文献放在一起，不会自动产生问题。

更强：迁移研究若把搬迁视为个人选择，家庭研究却显示照护义务由多名成员协商，两套解释对"谁的偏好决定迁移"给出不同答案。整合的意义在于解决决策单位和机制冲突。

四问检验：每次都重新回答

对任何"空白"使用这四问：

1. 我们已经知道什么？

写出有边界的知识，不写"存在大量文献"。说明针对什么对象、情境和证据，哪些判断相对稳定。

2. 究竟什么仍然无法解释或存在争议？

指出冲突发生在哪里。是方向、机制、概念、时间、尺度、群体边界，还是资料无法观察关键过程？

3. 为什么解决它会改变理解？

说明答案可能修正哪套理论、重新解释哪项发现、改变哪种测量，或使何种判断成立/失效。如果答案只是"增加一项案例"，问题通常仍然偏弱。

4. 什么证据能区分不同可能？

不要只写"需要更多数据"。说明需要观察哪些事件、叙述、文本变化、比较、时间顺序或反例。第四问也是通往下一章的桥。

如果四问中任何一问只能回答"因为以前没人做"，请继续修订。

The idea changed here

冻结的住房案例没有把"早期成年人研究较少"当成最终问题。更强的未决之处来自：普通移动和受迫不稳定被混用；地方关系损失不一定等于支持减少；关系可能反过来影响居住选择；短期中断、替代和恢复难以区分。这些问题会改变对已有结果的解释，因此比增加一个国家或年龄组更有科学分量。

### 通过标准（How do you judge whether the result is good?）

- [ ] 每个问题能否完整回答四问检验？
- [ ] "未决"是否指向解释、机制、测量、时间、尺度或边界，而非只指研究数量？
- [ ] 是否至少存在两种可区分的可能解释或判断？
- [ ] 解决问题后，现有理解会发生什么具体变化？
- [ ] 所需证据是否说到可观察的事件、材料或比较，而非"更多数据"？
- [ ] 是否检查了最接近的研究可能已经回答这个问题？
- [ ] 是否保留了会让问题降级或终止的证据？
- [ ] 这些问题是否与你的真实兴趣有关，而不是 Codex 挑出的抽象难题？

Red flags

- 每个问题都以"很少有研究"开头。
- 唯一的新意是国家、人群、时间或平台不同。
- "跨学科"只意味着把两个关键词拼在一起。
- "机制"之后只是列出中介变量，没有过程解释。
- "纵向研究不足"却说不出要观察哪段变化。
- 把群体差异当作天然属性，不解释制度或资源如何产生差异。
- 只提出一种解释，没有反例或替代解释。
- 所需证据写成某个著名数据集，而不是需要观察的内容。
- 最近似研究只看了标题或摘要，却断言问题仍未解决。
- Codex 生成的问题数量很多，但没有淘汰任何弱空白。

### 状态与门禁（Status / Gate）

PASS

至少有一个问题通过四问检验，有真实的科学不确定性，能指出可区分的解释和所需证据，并且最接近的研究尚未明显将它解决。

下一步：进入第四步，不急着写最终研究问题。先检查现实中什么证据能够观察这个知识困难。

REVISE

问题有潜力，但仍依赖"很少研究"、机制模糊、贡献不清，或最近似文献核查不足。

下一步：只选择最有吸引力的 1–3 个候选，补充最近似研究、反证或机制区分。重新做四问检验。

STOP

近似研究已经解决同一不确定性；所有候选都只是覆盖不足；或者没有现实证据可能区分解释。

下一步：记录终止原因。返回第二步选择另一场争论，或返回第一步改变研究问题空间。不要通过换国家、换样本或换方法来假装问题重生。

### 交接（Handoff）

- **Carry forward（带往下一步）**：3–7 个未决研究问题——四问检验通过、标注主要类型、列出最近似研究及证据层级、最强反对意见与终止/降级条件。PASS 段要求"进入第四步，先检查现实中什么证据能够观察这个知识困难"。
- **Leave behind（留在本步）**：只剩"研究较少"的弱空白；只提出一种解释无反例或替代解释的候选；通过换国家、换样本或换方法假装重生的"新问题"。
- **Human decision（必须人来定）**：哪个知识困难真正让你不满足于现有解释；它是否进入你希望归属的学科对话；解决它的意义是否足以支撑博士工作；是否愿接受答案可能推翻自己的预期；哪种问题类型符合你的研究气质和训练目标；哪些伦理、政治或个人位置需在问题形成时就面对；哪个未决问题值得带给潜在导师讨论。Codex 可说问题"结构更强"，但不能决定它是不是你愿意拥有的博士问题。
- **Blocking unknown（阻塞性未知）**：最近似研究是否已明显解决同一不确定性（需有边界的补充检索确认）；某些候选所需证据在现实中是否可观察（第四步检查招募、伦理、事件回忆、机构访问是否现实）。
