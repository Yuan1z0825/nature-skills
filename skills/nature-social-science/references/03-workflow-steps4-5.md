# 八步工作流 · 第四步与第五步：映射可观察证据 + 生成候选研究问题

## 目录

- 步骤 4 — Map Observable Evidence ｜ 映射可观察证据
- 步骤 5 — Generate Candidate Research Questions ｜ 生成候选研究问题

> **用途**：提供 Step 4（Map Observable Evidence）与 Step 5（Generate Candidate Research Questions）的逐字操作规范，用于把"哪里有材料"改写为"这些材料能让我知道什么、又不能让我知道什么"，并据此生成可被认真攻击的候选研究问题。
> **加载时机**：在用户已完成前三步、准备核查现实可观察证据，或要在证据边界内生成候选研究问题时加载。

## 步骤 4 — Map Observable Evidence ｜ 映射可观察证据

> 把"哪里有材料"改写为"材料能让我知道什么、不能让我知道什么"。

研究问题不是靠"有资料"就能回答。你需要的，是能够观察核心现象、过程、经验或意义，并且在单位、时间、范围、访问和伦理上与问题相匹配的证据。一份大型调查可能没有测到你关心的概念；一批可下载文件可能只保存了机构愿意公开的声音；一组访谈可以解释经验，却不能估计发生比例。证据地图（evidence map）的任务，就是把"哪里有材料"改写成"这些材料能让我知道什么，又不能让我知道什么"。

### 目标（What are you trying to achieve?）

为第三步留下的未决问题建立一张问题与证据的匹配表。对每条可能路线，至少判断：

- 构念或意义是否匹配：材料记录的是目标现象，还是一个方便的代理？
- 单位是否匹配：个人、关系、家庭、组织、地区、事件、文本或历史时期是否与问题一致？
- 时间是否匹配：能否看见顺序、变化、回忆、持续时间或关键历史节点？
- 覆盖是否匹配：谁或什么被纳入，谁缺席，样本、语料、场景、事件或档案系列的边界是什么？
- 访问是否现实：能否合法获得，是否需要审批、付费、合作或现场访问？
- 伦理是否可接受：同意、隐私、风险、敏感性、平台规则和研究者安全如何处理？
- 缺失与来源偏差是什么：不回答、失访、档案保存、删帖、选择性公开或招募偏差会怎样影响解释？
- 能支持什么主张：描述、比较、解释、过程理解、预测或因果判断的上限在哪里？

第四步的产物不是一份采购清单，而是一组带证据状态和关键未知项的可行路线。

### 为什么重要（Why does this matter?）

"数据可用"经常掩盖三个错位。

**名称错位**
变量叫"参与"，可能只问是否加入组织；你真正关心的却是决策权、发言方式或被排除的经验。文件里出现"公众参与"，也不代表参与真的发生。

**时间错位**
你想研究变化过程，资料却只有一次观察。你想知道某次事件之后发生什么，访谈只能在多年后回忆，或问卷波次无法确定先后。

**生成过程错位**
平台内容不是自然存在的完整社会记录。推荐、删除、账号退出和 API 限制都会决定你能看见什么。档案同样经过保存、整理和开放；行政记录服务于管理，不是为你的概念设计。

如果不绘制证据地图，你可能在选定问题之后才发现核心现象根本没有被记录。更隐蔽的风险是：你会悄悄缩小概念，让它适合现成资料，却继续使用原来更宽的理论语言。

### 需要什么输入（What do you need to give Codex?）

为每个优先未决问题提供以下信息：

```
未决研究问题：

已经知道什么：

需要区分的解释或机制：

必须观察的现象、经验、意义、关系、事件或材料：

需要的单位：

需要的时间顺序或历史范围：

可能的人群、机构、地点或语料边界：

我已经知道的资料来源：

我的访问、语言、预算、时间、伦理和技能约束：

我不能接受的证据妥协：
[填写或"不确定"]

不确定：
```

如果你只知道一个来源名称，也可以写上，但要标成 NAMED。不要因为它常被使用，就假设访问和内容已经确认。

### 应该做什么（What should Codex do?）

Codex 应从"需要观察什么"出发，而不是从"有哪些著名数据集"出发。

**Check Ask（核对清单）**

```
Check Ask
Construct or meaning 是直接观察、可辩护指标、弱代理还是不匹配？
Unit or material 个人、关系、组织、事件、文本或档案系列与问题一致吗？
Timing 能看见顺序、变化、持续时间或历史节点吗？
Coverage 谁或什么被纳入，谁缺席？
Access 当前是 NAMED、DOCUMENTED、ACCESS-CONFIRMED 还是 TESTED？
Ethics 同意、隐私、脆弱性、平台规则和研究者安全能管理吗？
Source-generation bias 记录、保存、公开、删除或招募过程改变了什么？
Claim ceiling 最多允许说什么，明确不能说什么？

定量例：变量名正确但时间窗不匹配，需 REVISE。质性例：访谈可以解释意义，不能估计总体比例。档案例：可搜索材料系统性遗漏问句中的行动者，可能 REVISE 或 STOP。不设总分。
```

**1. 同时考虑多种证据路线**

合法的证据包括但不限于：

- 横截面调查与问卷；
- 面板或其他纵向数据；
- 半结构式访谈、口述史和焦点小组；
- 民族志、参与式或非参与式观察；
- 公共与私人档案；
- 政策、组织和法律文件；
- 报纸、广播、影像和其他媒体语料；
- 平台内容和数字痕迹；
- 行政记录；
- 实验或准实验材料；
- 经授权进入的组织流程、会议或内部记录。

Codex 不应把它们排成固定高低等级。每种证据回答的事情不同。一组扎实访谈可能比拥有百万行却测错概念的数据更合适。

**2. 给每个来源标注证据状态**

- NAMED：只知道来源名称或有人提到过；尚未核查内容和访问。
- DOCUMENTED：已用可靠目录、问卷、档案说明、代码本或官方页面确认相关内容。
- ACCESS-CONFIRMED：已确认研究者本人在所需条件下能够合法取得，并了解审批、费用、地点和许可。
- TESTED：已通过小规模真实试取、样本/语料检查、访谈招募测试或其他最小现实检验。

状态不能跳跃。DOCUMENTED 不等于可行；官网说"研究者可以申请"也不等于你已经获得访问。

不要把这里的"证据状态"和第二步的"证据层级"混在一起：证据层级说明你把一篇来源核对到了题录、摘要、全文还是一手/官方资料；证据状态说明一整条研究证据路线目前只被提到、已有文档证明、本人已确认访问，还是已经实际测试。

**3. 检查来源如何产生**

Codex 应问：谁记录、为什么记录、何时记录、谁可能没有留下记录、什么会被删去或改写。对于调查，要看题目、回答者、适用人群和波次；对于访谈，要看招募和叙述条件；对于档案，要看保存和开放制度；对于数字痕迹，要看平台选择和抓取边界。

```
REFERENCE BOX — SOURCE-GENERATION BIAS

来源生成偏差问的是：这份证据为什么会以现在的形式存在？谁负责记录、保存、公开或删除？谁更容易出现，谁可能缺席？调查不回答、访谈招募、档案保存和平台推荐都会改变你最终看到的材料。
```

**4. 写出主张上限（Claim ceiling）**

每条路线都要有一句"这项证据最多允许我说什么"。例如：

- 访谈可以解释参与者如何理解和叙述过程，不能单独估计总体比例；
- 一次性问卷可以描述关联，无法观察个体变化；
- 机构文件可以分析正式分类和表述，不能直接代表执行经验；
- 平台行为日志可以记录可见行为，不一定说明动机或意义。

```
REFERENCE BOX — CLAIM CEILING

主张上限就是"这份证据和设计最多允许我得出什么结论"。它不只区分相关与因果，也适用于质性和历史研究。访谈可以解释经验与意义，机构文件可以分析正式表述，档案可以重建有记录的历史过程，但它们都不能自动代表未被访问、未被记录或未被保存的部分。
```

### 通过标准（How do you judge whether the result is good?）

- [ ] 41. 每条证据路线是否从问题需要观察的内容出发？
- [ ] 42. 构念、单位、时间和覆盖是否分别检查，而不是只写"相关"？
- [ ] 43. 是否使用官方或一手资料核实 DOCUMENTED 以上状态？
- [ ] 44. NAMED、DOCUMENTED、ACCESS-CONFIRMED 和 TESTED 是否没有被混用？
- [ ] 45. 是否写明每种证据不能支持什么主张？
- [ ] 46. 招募、失访、档案保存、平台选择、文件公开或行政生成偏差是否可见？
- [ ] 47. 伦理、许可和研究者安全是否影响 Gate，而非只作备注？
- [ ] 48. 是否给出了小而明确的下一步核验动作？

Red flags

- "这是公开数据，所以可以自由使用。"
- "该变量名包含信任，因此可以测量制度信任。"
- "样本很大，因此研究可行。"
- "论文使用过这个资料，所以我也能获得。"
- "访谈可以证明某机制导致了结果。"
- "公开帖子不需要伦理考虑。"
- "档案是历史事实的完整记录。"
- "行政数据比自报数据客观"，却不讨论记录目的和缺失。
- 把 DOCUMENTED 写成"数据已确认可用"。

- 笼统推荐"混合方法"，没有说明每种证据分别解决什么。

### 状态与门禁（Status / Gate）

如果你只完成了 Quick Run，Gate 只决定是否值得进入 Deep Run：

- PASS：至少有一条路线初步匹配，并且关键未知可以核实。选择 1–3 条路线进入 Deep Run。
- REVISE：问题要求观察的内容仍不清楚，或路线只是资料名称。先改写"必须观察什么"，再跑一次 Quick Run。
- STOP：所有路线都明显测错概念、无法访问或不可接受。返回第三步。

完成 Deep Run 后，再使用下面的 Gate 决定是否把证据地图带入第五步。

**PASS**
至少有一条证据路线在构念/意义、单位、时间和覆盖上与未决问题相容；访问和伦理看起来现实；关键未知项有可执行的核验办法。此处的 PASS 仍不代表已完成 pilot。

下一步：保存证据地图。等进入第五步后，只在这些证据边界内生成候选研究问题。

**REVISE**
来源可能存在，但测量偏弱、时间错位、访问未确认、伦理方案不足，或它只能回答比原问题更窄的内容。

下一步：选择一种修订：核实关键来源、寻找另一种证据、降低主张，或回到第三步重写未决问题。不要把 DOCUMENTED 升级为可行。

**STOP**
核心现象无法被观察；访问依赖不现实的机构协议；关键群体不能安全招募；材料使用不合乎伦理；或所有路线只能回答与原问题不同的事情。

下一步：记录哪项硬门槛失败。返回第三步选择另一个未决问题，或回到第一步调整研究空间。不要用一个方便的代理偷偷替代原目标。

### 交接（Handoff）

- **Carry forward（带往下一步）**：已保存的证据地图（evidence map）：每条证据路线的状态、构念/意义/单位/时间/覆盖匹配情况、主张上限、不能支持的主张、关键未知项与最小核验动作；以及 Gate 判定的证据边界（只在这些边界内生成候选研究问题）。
- **Leave behind（留在本步）**：资料采购清单式的罗列、仅标注 NAMED 而未核验的来源名称、未被 Gate 接受的路线、缩水后未改写的原问题概念。
- **Human decision（必须人来定）**：
  - 哪些观察是问题不可妥协的核心；
  - 一个代理指标或间接材料是否仍能支持你愿意作出的主张；
  - 你是否愿意承担访谈、田野、档案、编程或受限数据的时间和训练成本；
  - 哪些伦理和安全风险不能接受；
  - 是否愿意缩小或改变问题来匹配现实证据；
  - 哪些访问条件必须向导师、机构、档案员或数据提供方亲自确认；
  - 证据路线是否仍然让你感到这是自己的项目。
  - Codex 可以比较资料属性，不能替资料提供方授权，也不能替伦理委员会作判断。
- **Blocking unknown（阻塞性未知）**：参与者招募方式、平台材料使用伦理、申诉记录访问、字段/权限/伦理确认、版本与更新时间、平台条款与抽样边界等未确认项；若只完成 Quick Run，关键未知是否可核实仍为未知。

## 步骤 5 — Generate Candidate Research Questions ｜ 生成候选研究问题

> 在证据边界内生成 6–12 条可被认真攻击的候选研究问题。

现在才开始写研究问题。

前四步已经限定了研究空间、绘制了领域结构、找出了尚未解决的知识问题，并检查了现实中能够观察到什么。第五步的任务，是把这些材料组合成一组可以被认真攻击的候选研究问题，而不是让 Codex 凭空发明听起来新颖的题目。

候选池通常保留 6–12 条。数量太少，你容易爱上第一种表述；数量太多，差异往往只是换国家、换人群或换方法。

### 目标（What are you trying to achieve?）

通过三条路线生成一组有意保持差异的候选研究问题：

- 1. 问题驱动（problem-driven）：什么问题能够减少第三步识别出的知识不确定性？
- 2. 证据驱动（evidence-driven）：第四步确认的新观察、材料、序列或比较，使什么原本难以回答的问题变得可问？
- 3. 机制驱动（mechanism-driven）：什么过程可能产生现象，不同解释会留下什么不同痕迹？

每条候选都要落在一张简短的 Candidate RQ Card 上。卡片必须具体到可以被反驳：它要写出知识问题、准确问句、核心概念或解释焦点、研究对象或材料、证据路线、拟议机制、主张上限、贡献假设和最可能的致命缺陷。

这一步只负责生成和澄清，不负责证明候选新颖、可行或达到博士规模。那些判断分别留给第六步和第七步。

### 为什么重要（Why does this matter?）

如果只让 Codex "根据我的兴趣给十个博士题目"，它很容易生产三类伪差异：

- 同一问题换了不同国家、年龄组或行业；
- 同一问题换了访谈、问卷或机器学习方法；
- 同一变量关系换了几个近义词。

这些句子看起来不同，却没有提出不同的知识任务。

另一个风险是过度服从现成证据。证据驱动不等于"数据里有什么就研究什么"。一项新资料只有在它能观察此前看不见的过程、比较或意义，并因此改变原有问题时，才构成有价值的生成路线。

第五步还要对抗"第一问依恋"。你可能已经带着一条暂定问题进入流程。它可以成为候选之一，但不能因为写得最早就得到保护。Mode C 学生即使跳过广泛生成，也应至少写出：

- 一条对原问题的认真重构；
- 一条能够解释同一知识困难的强替代方案。

### 需要什么输入（What do you need to give Codex?）

不要粘贴前四章的所有对话。只提供当前仍然有效的摘要。

```
我的入口模式：Mode A / Mode B / Mode C

暂定研究空间：

我准备推进的 1–3 个未决研究问题：

每个问题的四问检验摘要：
- 已知：
- 未解或有争议：
- 为什么解决后会改变理解：
- 什么证据能区分不同可能：

仍然存活的证据路线及状态：
- 路线：
- 状态：NAMED / DOCUMENTED / ACCESS-CONFIRMED / TESTED
- 能支持的主张：
- 不能支持的主张：

需要比较的解释或机制：

我的硬约束：

如果我已有暂定研究问题，原句是：
[没有则写"无"]

仍然未知：
```

输入可以不完整，但不能掩盖未知。例如，访问尚未确认时写 DOCUMENTED，不要写"数据可用"；不知道最合适的方法时写"不确定"，不要要求 Codex 替你包装一种高级方法。

### 应该做什么（What should Codex do?）

Codex 应先检查输入是否足以生成问题，再从三条路线提出候选。

**从知识问题出发**
问题驱动的候选要明确：现有理解在哪里冲突、失效或无法区分。问句不应只询问"是否存在关系"，而要与第三步的知识困难相连。

**让证据改变可问的问题**
证据驱动的候选要说明：这项证据提供了什么以前缺失的观察能力。它可能是时间顺序、行动过程、负案例、制度变化、跨材料比较或参与者意义，不只是更多样本或更多变量。

**把机制写成可观察过程**
机制驱动的候选要列出至少两个竞争解释，以及它们会在数据、叙述、行为、文件、历史记录或事件序列中留下的不同痕迹。机制不是一个听起来理论化的名词。

**让每条问题接受主张上限**
问句的动词必须与证据相称。材料只能支持解释参与者意义时，不要写成总体因果效应；档案只保存正式记录时，不要把沉默者的经验写成已被观察；一次性关联资料不能回答个体变化。

**制造真正差异，而不是表面变体**
Codex 应为每条候选说明它与其他候选的差异来自哪里：知识问题、解释、观察对象、时间逻辑、分析尺度或贡献类型。若差异只是地点、样本或方法，应合并或重写。

Codex 不应在本步进行全面新颖性结论、可行性评分、导师匹配或最终排序。它可以指出明显缺口和致命风险，但不能替第六步和第七步作判决。

**Copy-paste prompt**

短预览：把已通过的未决问题、证据路线和 claim ceiling 交给 Codex；要求它从问题、证据和机制三条路线生成 6–12 张 Candidate RQ Cards，合并只换地点、样本或方法的伪变体，并禁止排序。

### 输出形态（What should the output look like?）

**微型示例：正式支持存在，学生为什么仍不披露困难？**

```
HYPOTHETICAL TEACHING EXAMPLE — NOT A VERIFIED TOPIC
以下内容只是展示三种生成路线，不是经过文献核实的选题建议。

未决问题摘要
高校可能提供正式经济支持，但我们仍不清楚，学生在具体求助互动中如何判断披露困难是否安全、必要或会带来污名。

候选 A：问题驱动
路线：问题驱动
知识问题：正式支持的存在无法解释学生为何在求助互动中披露或隐瞒经济困难。
研究问题句：第一代大学生如何在与学业支持人员的互动中判断是否披露经济困难？
焦点：披露判断、制度信任、预期污名和互动线索。
人群与情境：一所或少数几所高校中曾考虑寻求学业支持的第一代学生。
证据：参与者访谈；若获许可，可加入支持流程文件或有限观察。
拟议机制：对保密性、应得性和后果的判断影响披露。
竞争解释：决定主要由实际资格和资源需求决定，而不是互动判断。
可观察痕迹：关键转折叙述、负案例、不同接触环节的判断变化。
主张上限：解释受访者如何形成披露决定；不能估计总体披露率。
贡献假设：把"是否使用支持"重新解释为互动中形成的判断过程。
可能致命缺陷：只能招募已经成功接触支持系统的人，无法观察未披露者。

候选 B：证据驱动
若档案或机构流程文件能够按时间保存政策表述的变化，可以问：制度对"可披露困难"的正式分类如何变化，以及这些变化重新界定了哪些学生被视为适格求助者。这个候选研究的是制度分类，不应假装回答学生实际经验。

候选 C：机制驱动
可以比较两种解释：学生不披露主要源于污名预期，还是源于无法识别求助入口和资格。候选问题必须说明，访谈叙述、信息接触序列或负案例怎样区分二者，而不是简单把"污名"和"信息"列成两个变量。

三个候选处理同一片领域，但知识任务、观察对象和主张上限不同。这才是有用的候选差异。
```

### 通过标准（How do you judge whether the result is good?）

- [ ] 52. 每条候选是否对应第三步已经识别的知识问题，而不只是一个主题？
- [ ] 53. 问句是否准确到另一个研究者能指出它可能错在哪里？
- [ ] 54. 候选池是否真实使用了问题、证据和机制三条路线，而不是把同一句话贴上三个标签？
- [ ] 55. 至少三条候选是否在解释、时间、尺度、材料或贡献逻辑上实质不同？
- [ ] 56. 证据状态和主张上限是否从第四步继承，且没有被悄悄升级？
- [ ] 57. 机制是否包含过程和可观察痕迹，而不只是一个变量或主题名称？
- [ ] 58. 每张卡是否写出了最可能的致命缺陷和一个明确核实动作？
- [ ] 59. 输出是否停在候选生成，没有排名、自动选择或宣称通过后续审查？

Red flags

- "首次研究 A 国 B 群体中的 C"，却没有说明知识理解会怎样改变。
- 12 条问题只有地名、样本或方法不同。
- 所有候选都重复学生原来的关系方向。
- 把"有一份可下载数据"写成问题重要性的理由。
- 问句承诺因果、总体比例或完整历史过程，证据却不支持。
- "机制"栏只有一个理论名词、中介变量或访谈主题。
- 贡献栏写"填补空白""提供启示"，没有具体知识变化。
- Codex 以流畅程度、新潮程度或方法复杂度给候选打分。
- 将 DOCUMENTED 写成"访问已解决"。
- 候选刚生成就被称为"最优""最可行"或"最具博士潜力"。

### 状态与门禁（Status / Gate）

**PASS**
候选池通常包含 6–12 条明确问句；每条都连接有后果的知识问题和可观察证据；至少三条存在实质差异；问题、证据和机制三条路线都被认真尝试；未知和致命风险已经写出。

下一步：冻结这一版候选卡，不再润色。把全部候选带入第六步，让独立的批评角色寻找它们无法存活的理由。

**REVISE**
候选仍是主题、伪变体或方法包装；主张超过证据；机制没有可观察痕迹；或者输入中的未决问题和证据路线太模糊。

下一步：根据失败原因返回第三步或第四步。只修正造成伪问题的那一环，再重新生成，不要靠增加数量掩盖问题。

**STOP**
没有任何候选能够同时连接有后果的知识问题与现实可观察证据，或所有候选都必须依赖已经被第四步否定的证据路线。

下一步：停止这组生成。保存候选和停止原因，返回第三步选择另一项未决问题；必要时回到第一步重新划定研究空间。

### 交接（Handoff）

- **Carry forward（带往下一步）**：冻结的 6–12 张 Candidate RQ Cards（每条含知识问题、准确问句、焦点、对象/材料、证据路线与状态、拟议机制、竞争解释、可观察痕迹、主张上限、贡献假设、致命缺陷、核实动作与假设未知）；从第四步继承且未升级的证据状态与 claim ceiling。
- **Leave behind（留在本步）**：新颖性结论、可行性评分、导师匹配或最终排序；只换地点/样本/方法的伪变体合并结果；刚生成即被标注为"最优/最可行"的宣称。
- **Human decision（必须人来定）**：
  - 哪些知识问题真的值得你继续拥有，而不只是容易写成问句；
  - 哪些候选代表你愿意进入的学术对话；
  - 哪种主张上限仍然足以维持你的兴趣；
  - 哪些解释值得被放在真正的竞争关系中；
  - 哪些候选虽不成熟，却值得带入第六步接受攻击；
  - Mode C 中，你是否愿意让原来的问题被重构或淘汰。
  - Codex 可以扩大选择空间和暴露伪差异，不能替你判断哪条问题值得投入数年。
- **Blocking unknown（阻塞性未知）**：未决问题和证据路线若仍模糊则需回第三步/第四步；哪些候选的致命缺陷尚无明确核实动作；哪些证据状态尚未达到 ACCESS-CONFIRMED / TESTED 而可能影响后续可行性。
