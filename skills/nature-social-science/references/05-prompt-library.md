- 总览表

> **用途**：为社科博硕选题工作流的每一步（Step 1–8）提供可直接复制粘贴给 agent 调用的提示词，每条均附元数据字段与逐字正文。

## Step 1 — Define the Research Search Space

#### Interest Mapper

- **When to use it**：用于把兴趣、宽泛主题或暂定问题拆成一个有边界的研究问题空间。此时不生成候选研究问题。
- **Required input**：
  - 当前入口模式；
  - 感兴趣的现象或过程；
  - 个人兴趣来源；
  - 已知对象、材料、情境和时间；
  - 排除项与现实硬约束；
  - 当前最大疑问。
- **Stop condition**：得到研究问题空间和 Step 1 Gate 后停止。
- **What to save**：保存一页 Research Search Space：概念边界、替代词、对象/材料、情境、时间、尺度、排除项、硬约束、待决定事项和 Gate。

**Copy-paste prompt（逐字，可直接使用）**

```text
我正在使用 Codex 设计一个可能的博士研究方向。当前只完成"研究问题空间"这一步，不要生成候选研究问题。

我的入口模式：
[Mode A / Mode B / Mode C]

我的当前输入：
- 感兴趣的现象、过程或主题：[填写]
- 我为什么持续关心它：[填写]
- 已想到的参与者、人群、组织或材料：[填写或"不确定"]
- 可能相关的地点、制度或历史情境：[填写或"不确定"]
- 关心的时间范围或变化过程：[填写或"不确定"]
- 已接触的概念、理论或文献：[填写或"不确定"]
- 明确不想研究的内容：[填写]
- 实践硬约束，包括语言、地点、时间、预算、权限、伦理和技能：[填写或"不确定"]
- 当前最大的疑问：[填写]

任务：
1. 把核心表达拆成不同的现象、过程、经验、意义或关系，并指出哪些含义不能混用。
2. 提供后续检索可能需要的相邻概念和替代表达，说明它们与核心兴趣的区别。
3. 分别列出可能的参与者/材料、情境、时间和分析尺度选项。
4. 找出我已经暗含的方向、因果、价值或方法预设。
5. 提出 2–4 种研究问题空间边界方案，并说明每种方案保留什么、排除什么、可能错过什么。
6. 根据我的兴趣和硬约束，形成一份暂定搜索空间，但把仍需我决定的内容明确列出。

禁止：
- 不要生成博士研究问题、题目或假设。
- 不要声称存在研究空白或新颖性。
- 不要默认使用定量、定性、因果或任何特定方法。
- 不要因为某个数据集、语料或方法容易取得就把它当作研究问题。
- 不要把我的个人兴趣写成已经得到证明的学术重要性。

证据与核实要求：
- 这一阶段以概念澄清和边界设计为主。
- 如果为了澄清术语使用外部资料，请给出来源，并标明是题录、摘要、全文还是一手/官方资料。
- 对没有核实的学科判断标注"待核实"，不要编造代表性文献。

请按以下格式输出：
A. 我的兴趣核心，用 2–3 句话重述
B. 概念/现象分解表
C. 相邻概念与替代检索词
D. 参与者或材料、情境、时间、尺度选项
E. 隐含预设与风险
F. 2–4 种边界方案
G. 建议的暂定研究问题空间
H. 明确排除项
I. 仍需我决定的事项
J. Gate 建议：PASS / REVISE / STOP，并说明理由

停止条件：
输出到研究问题空间和 Gate 为止。不要绘制完整文献版图，也不要生成候选研究问题。
```

> **占位符说明**：`[Mode A / Mode B / Mode C]`、`[填写]`、`[填写或"不确定"]`

## Step 2 — Map the Research Landscape

#### Research Landscape Mapper — QUICK RUN

- **When to use it**：第一次查看一个领域是否呈现出值得深入检索的结构。先运行本条；只有得到 PASS 且学生愿意继续，才使用 Deep Run。
- **Required input**：
  - Step 1 的暂定研究问题空间；
  - 核心概念及区别；
  - 对象、材料、情境、时间与尺度；
  - 已知替代词、文献或材料。
- **Stop condition**：得到轻量研究版图和 Quick Run Gate 后停止。
- **What to save**：保存检索语言、问题家族、解释/理论、反证、关键来源及证据层级、边界、未知和 Quick Run Gate。

**Copy-paste prompt（逐字，可直接使用）**

```text
请为我的博士选题探索做一次轻量"研究版图"扫描。目标是判断这个领域是否值得进入深入检索，不是生成研究问题，也不是完成系统综述。

我的研究问题空间：
[粘贴 Step 1 的暂定研究问题空间]

核心概念及已知区别：
[填写或"不确定"]

可能的人群、参与者、组织或材料：
[填写或"不确定"]

情境、时间和尺度：
[填写或"不确定"]

我已经知道的替代词、文献或材料：
[填写或"无"]

任务：
1. 为核心现象提出至少三组检索词，包括不同术语或相邻文献使用的表达。
2. 用有边界的初步检索识别 3–5 个主要问题家族和 2–4 套常见解释或理论。
3. 至少寻找一项会削弱初始想法的矛盾结果、零结果、反向关系或替代解释。
4. 选择不超过五项最能说明领域结构的来源，说明每项来源支持什么判断。
5. 指出一项重要的人群/情境/时间/尺度边界，以及一项本轮仍不清楚的内容。
6. 判断是否值得进入 Deep Run。

禁止：
- 不要生成候选研究问题、题目或假设。
- 不要按论文逐篇写摘要。
- 不要只找支持我起点的材料。
- 不要把"本轮没找到"写成"没有研究"。
- 不要声称搜索已经全面，也不要编造引文或结果。

证据与核实要求：
- 关键来源给出 DOI 或稳定链接。
- 标明来源核实到 METADATA ONLY、ABSTRACT LEVEL、FULL-TEXT LEVEL 或 PRIMARY/OFFICIAL 中的哪一级。
- 摘要层级只能支持初步判断；无法核实的内容写明"未知"。
- 简要记录检索日期、主要词组和明显遗漏。

请按以下格式输出：
A. 三组以上检索语言
B. 3–5 个主要问题家族
C. 2–4 套常见解释或理论
D. 至少一项矛盾、零结果、反向关系或替代解释
E. 不超过五项关键来源及证据层级
F. 一项重要边界
G. 一项关键未知
H. 对初始想法的一个挑战
I. Quick Run Gate：PASS / REVISE / STOP，并说明理由

停止条件：
完成轻量地图和 Quick Run Gate 后停止。不要做全面引文追踪，不要进入候选问题或证据审计。
```

> **占位符说明**：`[粘贴 Step 1 的暂定研究问题空间]`、`[填写或"不确定"]`、`[填写或"无"]`

#### Research Landscape Mapper — DEEP RUN

- **When to use it**：仅在 Step 2 Quick Run 得到 PASS 且学生本人决定继续时使用。用于建立按问题、解释和争论组织的深入版图。
- **Required input**：
  - Step 1 研究问题空间；
  - Quick Run 的概念、检索词、问题家族、反证和关键未知；
  - 明确排除项；
  - 种子来源；
  - 需要挑战的初始解释。
- **Stop condition**：得到完整 Research Landscape Map 和 Step 2 Gate 后停止。
- **What to save**：保存研究版图、关键来源表及证据层级、搜索边界、失败搜索、初始想法修订和 Step 2 Gate。

**Copy-paste prompt（逐字，可直接使用）**

```text
Step 2 Quick Run 已得到 PASS，我也决定继续。请为我的博士选题探索绘制一张深入的"研究版图"，而不是生成研究问题，也不是写按论文顺序排列的传统文献综述。

我的研究问题空间：
[粘贴 Step 1 的暂定研究问题空间]

核心概念及已知区别：
[填写]

可能的人群、参与者、组织或材料：
[填写或"不确定"]

情境、时间和尺度：
[填写或"不确定"]

相邻概念与替代检索词：
[填写]

明确排除：
[填写]

种子文献或已读材料：
[填写标题、DOI、链接或"无"]

我目前怀疑的关系或解释：
[填写；请把它视为需要挑战的假设]

任务：
1. 制定有边界的搜索策略，覆盖核心术语、替代术语和重要相邻文献。
2. 使用可靠学术来源检索；必要时从关键文献做向前、向后或相邻追踪。
3. 按问题家族、理论、机制、争论、常见证据、主流方法、相对稳固发现和重要边界组织结果。
4. 专门搜索并保留矛盾结果、零结果、反向关系和替代解释。
5. 说明看似矛盾的结果是否可能来自构念、样本、材料、时间、尺度或方法差异。
6. 标出仍未核实的判断和本轮没有覆盖的部分。

禁止：
- 不要生成候选研究问题、题目或假设。
- 不要按"论文 A、论文 B、论文 C"的顺序写综述。
- 不要只寻找支持初始想法的证据。
- 不要把"本轮没有搜到"写成"没有人研究过"。
- 不要因为某地点、人群或方法研究较少就称其为重要空白。
- 不要用摘要证据详细断言样本、方法、结果或局限。
- 不要编造引文、DOI、资料或研究结果。

证据与核实要求：
- 每个重要来源提供可核查标题和 DOI 或稳定链接。
- 将关键证据标为 METADATA ONLY、ABSTRACT LEVEL、FULL-TEXT LEVEL 或 PRIMARY/OFFICIAL。
- 只能访问摘要时，明确限制判断强度。
- 记录搜索日期、主要查询、语言/时间范围、访问失败和覆盖限制。
- 对近期、关键或互相冲突的研究优先核对全文；不能核对时明确标记。

请按以下格式输出：
A. 研究版图摘要
B. 主要问题家族
C. 理论与机制地图
D. 核心争论和竞争解释
E. 常见证据与主流方法
F. 相对稳固的发现
G. 矛盾、零结果与反向关系
H. 人群、情境、时间和尺度边界
I. 关键来源表：来源、用途、证据层级、主要限制
J. 搜索记录与未覆盖部分
K. 对初始研究问题空间的挑战
L. Gate 建议：PASS / REVISE / STOP，并说明理由

停止条件：
完成领域结构和 Gate 后停止。不要把未决之处改写成候选研究问题，不要进入证据审计或选题排序。
```

## Step 3 — Find Unresolved Research Problems

#### Unresolved Problem Finder
