# `nature-social-science` 技能

[English](README_EN.md)

`nature-social-science` 是面向社会科学及相邻人文学科的学术写作与选题论证工作台，覆盖选题构思、文献梳理、论证组织、学术表达四大要素。定量、质性、民族志、档案、文件、语料和数字研究均适用；判断标准始终相同：**问题是否清楚，证据是否匹配，主张是否诚实，项目是否能由这名研究者完成。**

## 适合用它做什么

- 把"我想研究 XX"式的兴趣，发展成有边界、可搜索的研究空间（Mode A）。
- 把宽泛主题或已知关系，收敛成具体的未决知识问题（Mode B）。
- 审计已有研究问题：证据是否匹配、主张是否说过头、是否经得起"审稿人 2"式攻击（Mode C）。
- 梳理领域文献版图：区分"研究少"与真正未决的知识问题，保留矛盾、零结果与替代解释。
- 设计证据路线并设定主张上限（claim ceiling），明确哪些结论证据撑得住、哪些撑不住。
- 评估候选选题的博士/论文可行性：硬失败条件、数据访问、伦理与时间匹配。
- 检查论文论证段落：过度断言、动词与证据不相称、概念混用。
- 准备导师沟通材料与开题/研究计划书的论证部分。

## 典型请求

- "我想研究社交媒体对青少年的影响，帮我找个论文题目。"
- "这个方向有人做过吗？我的选题新不新？"
- "帮我想想审稿人会怎么攻击这个研究问题。"
- "这个结论是不是说过头了？数据其实只支持相关关系。"
- "帮我把开题报告的论证部分理清楚。"

## 你需要提供

- 你的兴趣、宽泛主题或暂定研究问题（任选其一作为起点）。
- 你已经读过的关键文献、已有数据或方法偏好（如有）。
- 你的约束条件：时间、经费、数据访问、伦理边界、目标学位层次。

## 产出

- 一页搜索空间、领域版图、3–7 张未决问题卡。
- 1–3 条证据路线与每张候选 RQ 的候选卡（6–12 张）。
- 新颖性审计与 Reviewer 2 攻击记录、可行性档案、最多三张 Topic Cards 短名单。
- 论证段落的诚实表述修改建议与 red flags 清单。

## 边界

- 不替你生成一个"正确题目"，不保证新颖、录取、资助、发表或论文成功。
- 不把某种方法（定量、质性、因果推断等）当作高质量研究的默认答案。
- AI 的自信不是证据：不知道的一律写"未知"，不编造引文、来源或结果。
- 需要真人判断的环节（学科分量、资料获取、敏感参与者、导师意愿）会明确停下来，而不是替你决定。

## 相关技能

- `nature-writing`：自然科学 / Nature 风格的正文章节起草与重构。
- `nature-reviewer`：投稿前的模拟同行评审。
- `nature-polishing`：已有文稿的语言润色与术语一致性检查。
- `academic-investigation`：学者背景与学术诚信调查。
