# `nature-paper2word` 技能

[English](README_EN.md)

把学术论文或科研报告的 Markdown 稿件编译成符合期刊或学校规范的 Word（`.docx`）：声明式格式要求、Word 原生可编辑公式、三线表、公式编号与交叉引用、常用引文样式，导出前后各有一道检查。

## 适合用它做什么

- 把 `nature-writing` 等技能写出的 Markdown 稿子变成可直接提交的 Word。
- 按学校或期刊给出的规范排版：字号、行距、页边距、标题层级、三线表、页码页眉、目录。
- 同一份稿件导出多种版式（学位论文版、期刊投稿版）。
- 需要公式可继续编辑、编号自动对齐的论文，而不是公式截图或纯文本。

## 典型请求

- 「把这篇稿子导出成我们学校研究生院要求的 Word。」
- 「按这份期刊模板排版，公式按章编号，参考文献用 GB/T 7714。」
- 「同一份稿子，先按通用格式导一版，再按学院格式导一版。」
- 「公式和表格要能在 Word 里直接改，不要图片。」

## 你需要提供

- **稿件**：Markdown 文件。若手上是文字稿、PDF 或旧 `.docx`，先交给本技能整理成 Markdown，不改动原件。
- **格式要求**（可选）：一份文本文件，一行描述一种样式；不提供就用内置预设，按稿件语种自动选择。
- **文献**（可选）：`.bib` 文献条目。没有则文末不生成文献表，可在导出后用文献管理器插入。
- **场景信息**：中文还是英文，学位论文还是期刊投稿，目标期刊或学校名称。

## 产出

- 一个 `.docx`：公式为 Word 原生对象，三线表、题注、页码页眉、目录、文献表按格式要求生成。
- 导出前的检查结果：不符合稿件契约的地方带行号与改法；导出后的数值完整性与样式对账结果。
- 按需给出多个版式，同一份稿件共用一套内容。

## 边界

- 不做自定义封面、合并单元格、多栏排版、文字环绕图片；这些导出后在 Word 中补。
- 只支持公式的交叉引用；图与表的编号写在题注里。
- 目录页码与随章变化的页眉是 Word 域，打开时 Word 会询问是否更新。
- 不做 PDF、HTML、LaTeX 输出；不做幻灯片与基金申请书。

## 运行和依赖

本技能只有文档，引擎是 PyPI 上的 `md-to-word-docx`，装一次即可，技能文件不随引擎版本改动。使用前先确认命令可用：

```bash
md-to-word --version
```

没有输出就安装 `pip install md-to-word-docx` 后重新检查。完整词表、契约细则与能力边界在包内手册，`md-to-word --contract` 会打印它的绝对路径。

## 相关技能

- `nature-writing`：起草论文初稿与章节论证（上游输入）
- `nature-polishing`：英文润色与学术表达收束（上游输入）
- `nature-citation`：检索并导出文献条目（RIS / ENW / Zotero RDF）
- `nature-ref-verifier`：交叉核验参考文献元数据
- `nature-paper2ppt`：把同一篇论文转成组会或答辩用的演示文稿
